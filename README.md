# MEMEGINARIUM (Мемеджинариум)

> Классический Imaginarium / Dixit на вертикальных карточках с актуальными СНГ-мемами 2026 года.

🔗 **Прямой сайт игры (Vercel)**: **[https://memeginarium.vercel.app](https://memeginarium.vercel.app)**  
🔗 **Зеркало на GitHub Pages**: **[https://alimkhalelov.github.io/memeginarium/](https://alimkhalelov.github.io/memeginarium/)**  
📦 **Репозиторий**: **[https://github.com/alimkhalelov/memeginarium](https://github.com/alimkhalelov/memeginarium)**

---

## 🎮 Режимы игры

1. **Один телефон (Pass-and-play)**:
   - Передача смартфона из рук в руки по кругу.
   - Полноэкранная шторка приватности («Передайте телефон игроку») исключает подглядывание чужих карт.
2. **Мультиплеер по комнатам (P2P WebRTC)**:
   - Подключение по короткому 4-значному коду комнаты.
   - Децентрализованная синхронизация через PeerJS без отдельного платного бэкенда.
3. **Кастомные колоды мемов**:
   - Возможность загрузить свои мемы (JPG, PNG, WEBP, GIF) прямо из браузера через Drag & Drop.
   - Локальное сохранение колод в IndexedDB.

## 🎨 Дизайн и UI-принципы

- **Минимум подложек**: Контент и карточки живут прямо на плоской плоскости без вложенных контейнеров «карточка в карточке».
- **Кнопки без иконок и эмодзи**: Исключительно лаконичный текстовый экшен (`Ready`, `Vote`, `Next`, `Pass Phone`).
- **Плоский дизайн без теней и обводок**: `box-shadow: none`, `border: none`.
- **Минимальный размер шрифта**: **16px** (1rem) — абсолютный минимум во всём интерфейсе.
- **Progressive Disclosure**: Интерактивные элементы (поля ввода ассоциаций, кнопки голосования) появляются плавно только при выборе карты.
- **Всё второстепенное — в настройки `⋮`**: Таблица счёта, правила и смена колоды спрятаны в кнопку из трёх вертикальных точек.

## 🚀 Запуск и сборка

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Прогон тестов (Vitest)
npm test

# Проверка типов (TypeScript)
npm run type-check

# Сборка статического продакшн-бандла
npm run build
```
